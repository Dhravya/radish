# web

The [radish.dhr.wtf](https://radish.dhr.wtf) landing page. Astro + Tailwind,
static output.

```sh
bun install
bun run dev      # localhost:4321
bun run build    # → dist/
```

Deploy `dist/` anywhere static. The design follows the previous Next.js site —
indigo palette, Inter / Inter Tight, dark by default and remembered per visitor.
